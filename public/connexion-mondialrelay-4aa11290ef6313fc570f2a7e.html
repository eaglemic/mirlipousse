Relier votre compte Mondial Relay

Cette page chiffre vos paramètres sur votre téléphone. Elle ne les envoie à aucun serveur. Seul l’opérateur Mirlipousse détient la clé privée permettant d’ouvrir le fichier créé.

  1. Ouvrez votre compte professionnel Mondial Relay dans votre navigateur : Mon profil → Mes paramètres de connexion. Dans Connect, cherchez Administration → Configuration des API → API 1.
  2. Copiez le code enseigne et la clé privée API Mondial Relay. Si vous avez un code marque, ajoutez-le aussi. Aucun identifiant de connexion ni mot de passe n’est demandé.
  3. Créez le fichier chiffré ci-dessous, puis joignez ce fichier seulement dans votre conversation. Ne partagez ni les valeurs en texte ni une capture d’écran de vos paramètres.

Voir le guide officiel Mondial Relay ↗

Aucune valeur n’est conservée dans le navigateur. La connexion du compte aux relais et la livraison des articles CJ sont deux vérifications distinctes. Cette page ne crée ni compte, ni étiquette, ni expédition et ne prélève aucun paiement.

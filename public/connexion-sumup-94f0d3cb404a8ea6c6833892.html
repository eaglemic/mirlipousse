Cette page chiffre votre clé secrète sur votre téléphone. Elle ne l’envoie à aucun serveur. Seul l’opérateur Mini & Merveilles détient la clé privée permettant d’ouvrir le fichier créé.

  1. Votre clé est déjà créée ? Passez directement au champ ci-dessous. Sinon, ouvrez les clés API SumUp dans votre navigateur (Chrome ou Safari, pas l’application SumUp). Choisissez Créer, puis le nom Mini & Merveilles.
  2. Copiez la clé API secrète, pas la clé publique commençant par sup_pk_.
  3. Collez-la ci-dessous et créez le fichier chiffré. Joignez ensuite ce fichier seulement dans votre conversation.

Uniquement la clé API : aucun mot de passe bancaire, numéro de carte ou code de confirmation SMS. Le code marchand sera récupéré automatiquement lors de la vérification privée du compte. Aucun paiement n’est lancé ici.

Gardez la clé privée : ne l’envoyez ni en message ni en capture. Aucun champ n’est enregistré dans le navigateur ; votre presse-papiers reste sous votre contrôle. La validité de la clé SumUp sera vérifiée après l’import privé.
